## 1. 设计原则（四个来源，无一需要天赋）

| 原则 | 内容 |
| --- | --- |
| **① 规则兜底** | Material 3 默认组件优先，不自绘不魔改；8px 网格；**单色灰阶 + 单信号色**（v2）；字级 5 档封顶；一切对齐 |
| **② 抄成熟布局** | 屏1 抄 iOS 时钟/智能家居面板；屏2 抄 Apple Pay 刷卡页；屏3 抄 Streaks/Forest 统计页——不发明新布局 |
| **③ 电子纸视觉语言** | 硬件已定风格：纸感、1-bit 黑白、静态克制。App 与卡片必须像同一个世界 |
| **④ 客观量化** | 能测的全部测：对比度 / 触摸目标 / 拇指热区 / 3 秒测试（标准见 §6-A） |

### 设计语言："Digital Card"（2026-09-09 用户定稿）

硬件本体 = 3mm、无电池、无按钮、像一张数字卡片 → App 延续同一种感觉：**极简、编辑感、数字衣橱 + 卡片设计工具**。

参考分解（不模仿，合成自己的语言）：

- **Apple**：留白、发丝线、克制——chrome 退后，内容为主角
- **Kindle**：纸魂——纸底墨字、安静到消失的界面
- **Nothing**：点阵元信息——大写 micro 标签、等宽技术字符串、仪器般的诚实
- **Figma**：编辑器纪律——卡片是画布对象、1px 结构、精确网格

**合成原则：每个界面元素都表现得像一张卡片对象。**

- 屏1 = **数字衣橱**：物理卡片比例（296:128）的格子；英雄位（专注）= 抽出来的**实底墨卡**
- 屏2 = **编辑画布**：卡片悬浮居中 + 尺寸元信息（`296×128 · 1-BIT · RLE`，等宽 meta）
- 屏3 = **编辑感账本**：发丝线表行、巨大数字、micro 标签
- 动效仅用于状态转换（写入中脉冲），无装饰动画——静态是美德（电子纸哲学）

## 2. 设计系统 Token（唯一合法值，页面不得越表取色/取号）

### 2.1 颜色（含预计算对比度，基准 = 纸白底）

| Token | HEX | 用途 | 对比度 | 判定 |
| --- | --- | --- | ---: | --- |
| `paper` | `#FAFAF8` | 全局背景（Kindle 纸魂） | — | — |
| `ink` | `#141412` | 主文字 / 实底墨卡（英雄位） | 17.4:1 | ✅ 任意字号 |
| `inkSub` | `#6E6E68` | 次要文字 / micro 标签 | 4.8:1 | ✅ 正文可用 |
| `hairline` | `#E4E2DC` | 1px 结构线 / 非当前卡格描边（Apple/Figma） | — | 仅装饰 |
| `lineStrong` | `#8A8A85` | 仅卡片对象外框 | 3.3:1 | ⚠️ **禁止用作文字** |
| `onInk` / `onInkSub` | `#FAFAF8` / 70% | 墨卡上的纸色文字 | 17.4:1 | ✅ |
| `accent` 强调橙 | `#E8590C` | **行动色**：写入按钮底/演示标记/CTA（B 轮评审定稿：不用于状态强调） | 3.4:1 | ⚠️ 仅限图形与按钮底色；**橙底白字按钮文字须 ≥18px Bold**；禁止文字色 |
| （语义注） | — | **状态强调 = 墨黑 monochrome**：当前态 2px 墨边 + 墨色图标文字；记录英雄点=墨黑实心 | — | accentText 已退役（不再以橙色做文字，A4 自然合规） |
| `onAccent` 纯白 | `#FFFFFF` | 橙按钮上的文字 | 3.6:1(对橙) | 随 accent 规则 |

**全 App 只允许这一个彩色（accent）。** 卡片位图内只有 `ink`/`paper` 两色（1-bit）。

### 2.2 字级与字重（v2：5 级、3 字重 400/500/700）

| 级别 | 字号/字重 | 用途 |
| --- | --- | --- |
| Display | 44 / Bold / -0.5 字距 | 大数字、状态词（编辑感尺度对比） |
| Title | 20 / Bold | 区块标题、墨卡标签 |
| Body | 16 / Regular | 正文、按钮文字 |
| Micro | 11 / Medium / +1.2 字距 / 大写 | 微标签（Nothing 点阵感） |
| Meta | 12 / monospace | 技术元信息（UID/画布规格/时间戳） |

### 2.3 间距与网格

- **8px 网格**：所有间距取 8/16/24/32/48（4 仅允许用于图标-文字间隙）
- 页面左右边距：16（紧凑屏）或 24
- **亲密原则**：组内间距 < 组间间距（如 8 vs 24）

### 2.4 圆角与组件尺寸

| 元素 | 值 |
| --- | --- |
| 卡片对象圆角 | 4px（实体卡） |
| 控件圆角 | 8px（Figma crispness） |
| 衣橱格比例 | 296:128 = 物理卡比例（数字衣橱） |
| 主按钮最小高度 | **56px** |
| 次按钮/可点元素最小 | **48×48dp** |
| 底部 Tab 栏 | Material 3 默认 NavigationBar |

### 2.5 布局规则

- 单列布局、左对齐为主
- **主按钮必须落在屏幕下半 1/3（拇指热区）**
- **每屏有且只有一个视觉主行动**（唯一的实心大按钮，其余为次级样式）
- 语言：**App UI 中文；卡片画布状态词用英文大字**（FOCUSING 等，避开 1-bit 小字号中文渲染劣势）；卡片自定义留言区支持中文（≥24px 渲染）

```text
│  │ ● 专注中      │ │            │  │   FOCUSING    │ │          │    2h 14m        │
│  │   14:32 开始  │ │            │  │    14:32      │ │          │   ████████░░     │
│  └─────────────┘ │            │  │  ● 勿扰中      │ │          │                  │
│                  │            │  └───────────────┘ │          │  3 次  最长 47m    │

│  ┌───────────────┐ │            │                  │          │                  │

│  └─────┘└─────┘ │            │  │   ⟳ 写入中…    │  │          │                  │

│  └─────┘└─────┘ │            │                  │          │                  │

```

> **交互规则（2026-09-09 B 轮评审定稿）**：**专注翻转即写入**——点[专注]进屏2 自动发起写入（留言默认隐藏，"先加留言？"可展开转手动）；其余状态=预览→手动写入。状态强调=墨黑 monochrome，橙色仅行动色。
>
> **v3（2026-09-09 用户评审）**：定位是卡 → 屏1 **第一对象 = "我的卡现在是什么"**（卡对象本身：已写=真实位图+meta 行；未写=空白纸卡+NOT ON CARD YET 诚实标注）；数字衣橱退为第二层级。

## 5. 卡片预览同源原则（WYSIWYG）

```text
                CardRenderer（唯一渲染源，纯函数）
                      │
        ┌─────────────┴─────────────┐
        ▼                           ▼
  屏2 预览组件                  NFC 写入 payload
  （profile 画布位图整数倍放大，   （RLE 压缩后写卡）
    禁平滑/抗锯齿）
```

- 画布 = 当前 **DeviceProfile.canvas**（开发占位 296×128；真实硬件输入到位后仅更新 profile，预览组件自动适配、核心零改动）
- 位图**纯黑白两色**，无灰阶；纸质感由预览容器（边框/底色）模拟，不进位图
- 卡内文字：状态词 ≥40px、时间 ≥28px、自定义留言 ≥24px
- **预览骗人 = P0 缺陷**：预览与写入 payload 必须出自同一次 CardRenderer 调用

## 6. 页面完成检查清单（核心交付物）

### A. 客观检查（Claude 执行，须全绿）

| # | 检查项 | 标准 | 方法 |
| --- | --- | --- | --- |
| A1 | 颜色数量 | 全屏 ≤3 中性色 + 1 强调色，且不越 Token 表 | 代码审查 + 截图 |
| A2 | 字级/字重 | ≤4 级、≤2 字重 | 代码审查 |
| A3 | 间距网格 | 全部为 8 的倍数（4 仅限图标-文字） | 代码审查 |
| A4 | 对比度 | 正文 ≥4.5:1；≥24px Bold 大字 ≥3:1 | Token 预计算表 §2.1 |
| A5 | 触摸目标 | ≥48×48dp；主按钮高 ≥56 | 代码常量 |
| A6 | 主行动唯一 | 每屏实心主按钮 ≤1 | 截图检查 |
| A7 | 对齐 | 同组元素无视觉错位 | 截图 + 用户确认 |
| A8 | 静态分析 | `flutter analyze` 0 error | 命令 |
| A9 | 无溢出 | 窗口/真机运行无 OVERFLOWED 黄黑条 | 运行观察 |
| A10 | 导航深度 | 核心动作 ≤2 步可达 | 流程走查 |

### B. 直觉五问（用户回答，每问 <1 分钟，无需专业知识）

| # | 问题 | 通过标准 |
| --- | --- | --- |
| B1 | 3 秒内说得出这屏是干嘛的吗？ | 能 |
| B2 | 最重要的东西最显眼吗？ | 是 |
| B3 | 想不想点那个主按钮？ | 想 |
| B4 | 看着累/挤/吵吗？ | 不 |
| B5 | 和卡片像一个世界吗（纸感）？ | 像 |

> 任何"挤 / 看不清 / 不像能按的 / 说不上来但别扭"都是合格反馈——说出感受即可，诊断修复归 Claude。**任一问明确负面 → 不通过，热改后重检。**

### C. 产品特有检查

| # | 检查项 | 标准 |
| --- | --- | --- |
| C1 | WYSIWYG | 屏2 预览 = CardRenderer 位图本身（同源调用），非"示意图" |
| C2 | One Flip | 选状态 → 完成写入 ≤2 个动作 |
| C3 | 打点一致 | 写卡成功 = 打点时间戳；无"静默记录"路径 |
| C4 | 无实时承诺 | 界面不得出现倒计时/秒针/自动同步字样（卡片=快照原则） |
| C5 | Mock 隔离 | 桌面端自动走 MockCardWriter，不崩溃、可演示全流程 |

### D. 真机检查（手机接回后执行一次）

| # | 检查项 | 标准 |
| --- | --- | --- |
| D1 | 拇指热区 | 单手持机可及主按钮 |
| D2 | 写入反馈 | NFC 会话期间状态提示清晰（Android 静默模式下尤其） |
| D3 | 翻转引导 | 屏2 引导动画方向与实际翻转动作一致 |
| D4 | 卡片实拍比对 | 真卡刷新后与屏2 预览逐项一致（C1 的物理验证） |

### 通过标准

> **A 全绿 + B 无明确负面 + C1/C2 通过 → 页面交付。** D 项在真机可用时补验，不阻塞桌面交付。

## 8. V1 明确不做

- **深色模式**（纸感 = 单一浅色主题；电子纸本身无背光，深色无意义）
- 自绘组件 / 动画炫技（唯一例外：屏2 翻转引导动画）
- 卡片自由画布（只有模板 + 自定义文字区）
- 卡片画布上的中文状态词（状态词一律英文大字；中文仅出现在自定义留言区 ≥24px）
- 多语言（V1 仅中文 UI）
