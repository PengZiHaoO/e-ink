## 1. 架构分层

```text
┌─ L3 App 核心域（硬件无感）───────────────────────┐
│  S 状态域 · R 记录域 · P 档案域 · 用户旅程 · 三屏 UI │
└──────────────────┬─────────────────────────────┘
                   │ 只依赖抽象接口，不 import 平台/硬件细节
┌─ L2 硬件抽象层 ──▼─────────────────────────────┐
│  H1 DeviceProfile（画布/色深/内存/协议版本/字体/布局规则）│
│  H2 CardRenderer(profile, 状态, 文字, 时间) → 位图     │
│  H3 协议编解码 v0 · H4 RLE · H6 CardWriter 接口        │
└──────────────────┬─────────────────────────────┘
┌─ L1 平台适配层 ──▼─────────────────────────────┐
│  MockCardWriter(桌面) · NfcCardWriter(nfc_manager)    │
│  sqflite 存储 · CJK/Latin 字体资产 · 平台能力检测        │
└─────────────────────────────────────────────────┘
```

**依赖规则**：L3 → L2 → L1 单向依赖；L2 不知道 NFC 存在（只知道 CardWriter 接口）；L3 不知道画布尺寸（只知道 profile）。**换硬件 = 换 profile 参数 + 布局规则，L3 零改动**（M5 里程碑实证此原则）。

## 4. 数据模型 + 协议 v0

### 4.1 模型

```text
AppState      {currentState, since, customText, lastWriteTs, lastWriteStatus}
StateSession  {id, state, startTs, endTs?, note?}
CardBinding   {uid PK, nickname, profileId, boundAt, lastSeenTs}
UserProfile   {name, title, qrContent}
DeviceProfile {profileId, generation, canvasW, canvasH, colorDepth,
               memoryLimitBytes, protocolVersion, compressions[],
               fontRules{stateWordMinPx, timeMinPx, cjkMinPx},
               layoutRules{模板区域定义}}
```

时间一律 **UTC epoch 存储、本地时区显示**；UID 仅本地存储（隐私）。

### 4.2 协议 v0 字节表（与卡片固件的合同）

| 偏移 | 字段 | 类型 | 字节 | 说明 |
| ---: | --- | --- | ---: | --- |
| 0 | Magic | char[2] | 2 | `"FC"` |
| 2 | Version | u8 | 1 | 协议版本=0；代际协商用（Gen2 固件拒绝更高版本） |
| 3 | Flags | u8 | 1 | 保留=0 |
| 4 | DeviceID | u32 | 4 | 绑定 UID 哈希低 4 字节——防把 A 卡内容写进 B 卡 |
| 8 | ImageSize | u16 | 2 | 压缩后图像字节数 |
| 10 | Compression | u8 | 1 | 0=none，1=RLE |
| 11 | ImageData | var | ≤7.8K | 位图数据 |
| 尾 | CRC16 | u16 | 2 | CRC16-CCITT，覆盖 Magic~ImageData |

- **设计原则：bitmap-centric**——卡片固件是哑终端（收位图→刷屏），全部智能在 App；结构化字段仅留版本协商与防错写。
- **评审结论（2026-09-07）**：App 与固件两端同队开发，本协议为**活文档**——开发过程中对齐更新即可，不作为里程碑阻塞项。
- NDEF 封装：单条 MIME 记录 `application/x-focuscard`。
- 容量预算（占位）：ST25DV64K 8KB − NDEF 开销 ≈ **payload ≤ 7.9KB**；296×128 原始位图 4.7KB（不压缩也装得下）；文字态 RLE 后 <1KB。
