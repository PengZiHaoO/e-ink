# NFC 磁吸 · 无电池专注状态卡 —— 产品方案 V1.1

> **定位：** 一块让"勿扰"变成实体、把"专注"变成记录的卡。
> 核心原则：**卡片是快照，App 是活账本。**

## 1. 产品定义

> 一块贴在手机背面的、无电池、MagSafe 磁吸、NFC 碰一碰更新的电子纸卡。
> 它把"我在专注"变成一件**看得见的实体**，并把每次专注变成 App 里的**记录**。

### 目标规格

| 维度 | 规格 |
| --- | --- |
| 形态 | MagSafe 磁吸卡片（跨平台，无机型专属） |
| 屏幕 | 2.9" 黑白（备选 2.13"） |
| 供电 | NFC 13.56 MHz 无线取能 + 超级电容 |
| 通信 | NFC（无 BLE、无电池、无 IMU） |
| 磁吸 | MagSafe 兼容 + 可选桌面立架 |
| 交互 | 翻转即更新（App 开 → 翻转 → 完成） |

### 核心体验流程

```text
打开App → 点击开始专注
        ↓
翻转手机（背面朝上）
        ↓
NFC写入 + 取能
        ↓
储能电容充电（2~4 秒）
        ↓
卡片刷新 "FOCUSING 14:32"
        ↓
卡片静态、零功耗持续显示
        ↓
（专注结束）翻转回来 → NFC写入 → 卡片更新为下一状态
```

> **卡片** = 当前状态的快照（bistable，零功耗，不显示实时秒数）
> **App** = 专注记录的活账本（实时、可累计、可统计）

## 3. 屏幕：2.9"（或 2.13"）黑白

### 目标参数（V1.1 更新）

| 项目 | V1.1 推荐 | 说明 |
| --- | --- | --- |
| 尺寸 | **2.9"**（备选 2.13"） | 专注内容为文字/符号，足够 |
| 分辨率 | 随面板 | ~296×128 / ~250×122 级 |
| 颜色 | **黑白** | 专注符号无色彩需求 |
| 接口 | SPI | |
| 刷新 | 全刷优先 | |
| 厚度 | 尽量 < 1 mm | |
| ~~3.7" 800×480~~ | 降级为备选 | 仅当形态需要"身份卡"观感时才用 |

### 为什么下调屏幕规格

| 收益 | 说明 |
| --- | --- |
| 能量余量翻倍 | 2.9" 全刷 ~20-50mJ vs 3.7" ~80-200mJ |
| 刷新更快 | 2~4 秒即可完成，贴合 Go 标准 |
| 更薄更轻 | 直击"卡片"形态目标 |
| 成本更低 | 屏幕是 BOM 大头 |

### 选型原则（保留）

> 先找 2.9" 低功耗电子纸 → 看厂家实际 Driver IC → 再适配 MCU（UC8176 / SSD1677 等以实际为准）。

### 刷新策略：局部优先（硬件约束）

**核心原则：能局部就不全刷，能 1-bit 就不灰度。**

```text
日常更新（状态/时间变化） → 局部刷新 → ~0.3s + 充电 <1s
偶发大改样（模板切换）    → 干净全刷 → ~2s，挑用户不着急的时刻
每 N 次局部后             → 全刷一次清掉累积重影
```

**关键机制：**

- 电子纸 bistable：没变的像素自行保持，不重复驱动 → **固定模板 + 只更变区域**
- 内容为"FOCUSING 14:32"式固定模板，只驱动时间 / 状态词那一小块
- 纯 1-bit 黑白：无灰度波形，LUT 天然更短
- **自选优化 LUT**：禁用厂商默认快速模式（费电），选"够干净就停"的短波形

**双重收益：**

| 维度 | 全刷 | 局部刷新 |
| --- | ---: | ---: |
| 面板时间 | 2~2.5s | ~0.3s |
| 能量需求 | 20~50 mJ | 3~10 mJ |
| 充电到可用 | 2~4s | **<1s** |

> 面板时间降下来，所需能量也降下来 → 充电等待同步缩短。这是"体验极致"的主要杠杆。

**诚实下限：**

| 目标 | 下限 | 代价 |
| --- | ---: | --- |
| 小区域局部更新 | ~0.3s | 几乎无代价 |
| 全屏干净刷新（优化后） | ~0.5~1s | — |
| 再往下压 | ~0.1s | 对比度下降 + 重影（文字糊） |

**单次刷新耗时预算（抛开充电）：**

| 环节 | 全刷 | 局部 |
| --- | ---: | ---: |
| NFC 传输（~5KB） | 0.1~0.5s | 0.1~0.5s |
| MCU 解析 / 解压 | ms 级 | ms 级 |
| 面板波形执行 | 2~2.5s | ~0.3s |
| **合计** | **~2.2~3s** | **~0.4~0.8s** |

> ⚠️ 感知等待 ≈ 充电时间 + 面板时间。**上限杠杆仍在能量侧**（线圈耦合 / harvest IC / 电容选型）；面板优化把 6s 变 2s，能量优化把 2s 变 1s。

## 4. MCU

### 首选：STM32U031
- 超低功耗、Cortex-M0+、SPI、RAM/Flash 够图像缓存与协议处理、成本低

### 备选：STM32L011
- 数据处理极简单时够用

### 主要工作

```text
NFC数据 → 协议解析 → 图片解压 → Frame Buffer → SPI → E-Ink
```

同时负责：电压检测 / 电容电量检测 / 屏幕状态控制 / NFC 事件唤醒 / 异常复位。

## 5. NFC 与能量获取（最大技术风险）

### 架构原则：通信与供电分开优化

```text
                  NFC Coil
                     │
              13.56 MHz RF
                     │
          ┌──────────▼──────────┐
          │ NFC Front End       │
          │ + Energy Harvest    │
          └──────────┬──────────┘
                     │
             ┌───────▼───────┐
             │ Energy Storage │
             │ 10~100mF      │
             └───────┬───────┘
                     │
                  3.3V Rail
                     │
          ┌──────────┴─────────┐
          │                    │
         MCU                 E-Ink
```

### 能量账本（估算，待 EVT 实测）

```text
手机 NFC 对标签可稳定取出：10~30 mW（耦合好时更高）

单次全刷所需能量（估）：
  2.13" 黑白   ~10-30 mJ   → 充电 ~1-3 秒
  2.9"  黑白   ~20-50 mJ   → 充电 ~2-4 秒
  3.7"  黑白   ~80-200 mJ  → 充电 ~5-15 秒
```

> 专注卡内容小（文字 + 符号，几百 B~几 KB）、刷新稀（一次会话 2 次）、两次刷新间静态零功耗 —— 是**能量负担最小的形态**。

### 分阶段策略

| 阶段 | 方案 | 目的 |
| --- | --- | --- |
| 第一阶段 | NXP NT3H 系列开发方案 | 快速验证通信 + 取能 |
| 第二阶段 | 专用 NFC Energy Harvesting 方案 | 提高实际可用功率 |

## 6. 储能电容（超级电容）

### 定位：Refresh Energy Buffer，不是电池

```text
手机NFC靠近 → 持续收能 → 电容电压上升 → 达到启动阈值 → MCU启动 → 刷新 → 电容放电 → 完成
```

### 容量选择：逐级实测

测试 **10mF / 22mF / 47mF / 100mF**，以示波器实测反推：

- NFC 输入功率
- 电容充电时间
- E-Ink 峰值电流
- MCU 峰值电流
- 一次完整刷新消耗的能量

---

## 7. 供电架构

```text
NFC → RF Rectifier / Harvest → 储能电容 → Power Path
                                            ├──── MCU 3.0/3.3V
                                            └──── E-Ink电源
```

⚠️ 不要简单用普通 LDO 串起来（刷新有瞬时电流）。需要：欠压检测 / Power Good / 电容电压检测 / MCU brown-out / E-Ink 独立供电控制。

## 8. NFC 天线

- 方案：**FPC NFC Coil**（不要一开始用 PCB 小线圈）
- 目标：13.56 MHz 精确调谐
- 测试：VNA / 手机实测 / 不同 MagSafe 手机 / 不同磁吸位置

### ⚠️ V1.1 新增：翻转姿态耦合

iPhone NFC 读头在**背面上方**，MagSafe 磁环在**中央**。翻转姿态（背面朝上）下，卡片线圈必须与读头**稳定耦合**——这是 EVT-2 专项。

## 9. MagSafe 与 NFC 的堆叠

### 建议堆叠（自上而下）

```text
正面
│
├─ 保护层
├─ E-Ink
├─ FPC
├─ 主PCB
├─ NFC线圈
├─ 铁氧体隔磁
├─ MagSafe磁铁
├─ 后盖
│
手机
```

### ⚠️ 不要凭经验定线圈与磁环位置

做 **2~3 种结构样** 后直接测手机实际取电功率：

| 方案 | 说明 |
| --- | --- |
| A | NFC 线圈在磁环内 |
| B | NFC 线圈包围磁环 |
| C | NFC 线圈与 MagSafe 区域部分错位 |

**V1.1 新增**：额外测**翻转姿态（背面朝上）**下三种方案的耦合稳定性。

## 15. 工程验证顺序

> **不要直接开始画最终 PCB**，先完成四个实验。

### EVT-0：能量实验

```text
手机NFC → 线圈 → Harvest → 电容
```

测：**手机贴上（含翻转姿态）到底能获得多少 mW。**

### EVT-1：屏幕实验

```text
电容 → 3.3V → MCU → E-Ink
```

测：**一次完整刷新需要多少 mJ + 耗时**（2.13" / 2.9" / 3.7" 各测一次）。

**必测指标（目标值）：**

| 指标 | 全刷 | 局部刷新 |
| --- | ---: | ---: |
| 能量（mJ） | 20~50 | 3~10 |
| 充电到可用阈值 | 2~4s | <1s |
| 面板波形执行 | ≤2.5s | ≤0.3s |
| 重影可接受度 | 干净 | 少量可接受，N 次后需全刷清影 |

### EVT-2：合体实验 + 翻转耦合专项（最关键）

```text
手机 → NFC → 磁环 → 铁氧体 → 线圈 → 电容 → 卡片刷新
```

**专项：翻转姿态（背面朝上）下的耦合稳定性 + MagSafe 磁环干扰。**

**通过标准：**

| 配置 | 标准 |
| --- | --- |
| 2.9" | 贴 2~4 秒稳定完成一次刷新 |
| 3.7"（如保留） | 8~15 秒 |
| 翻转姿态 | 重复 50 次，失败率 < 5% |

### EVT-3：极限测试

覆盖：iPhone/Android 不同机型 / 手机壳厚度 / MagSafe 位置偏移 / 线圈偏移 / 翻转角度 / 温度 / 电容初始电压。

## 17. Go / No-Go 指标

### 第一阶段只回答一个问题

> **手机 NFC 在 MagSafe 完整结构 + 翻转姿态下，能否在合理时间内提供足够能量，让 2.9" 黑白电子纸完成一次可靠刷新？**

| 结果 | 动作 |
| --- | --- |
| **Yes**（2.9" 贴 2~4 秒稳定刷新） | 继续做 |
| **No** | 不要先换 MCU，按优先级调整 |

**调整优先级：**

```text
屏幕分辨率 → 屏幕尺寸 → NFC线圈 → 磁环结构 → 刷新策略
```

## 附录：能量账本速记

- 手机 NFC 可取：**10~30 mW**
- 2.9" 黑白全刷：**~20-50 mJ → 2~4 秒**
- 3.7" 黑白全刷：**~80-200 mJ → 8~15 秒**
- 专注卡 = 内容小 / 静态长 / 刷新稀 / 屏可小 → **能量负担最小形态**
- 卡片只写快照，不写实时时钟（bistable 不能持续刷新）
