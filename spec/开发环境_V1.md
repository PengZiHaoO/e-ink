## 2. 连接架构

```text
Windows                          WSL2 (Ubuntu 24.04)
─────────                        ─────────────────
USB: PKT110 ──usbipd bind/attach──► /dev/bus/usb/001/00X
  (BUSID 2-2, Shared=持久)              │ udev 规则 → 0666
                                   Linux adb server ──► device（已授权）
                                        │
                                   Flutter ──► PKT110 (android-arm64, API 36)
```

**关键概念：**

- `bind`（共享许可）= **持久**，做过一次，重启也在
- `attach`(实际接入 WSL) = **易失**，拔线 / 重启电脑就掉，每次插回要重做
- BUSID `2-2` 对应**物理 USB 口**——换口会变 BUSID（脚本会自动识别，新口需一次性重新 bind）

## 3. 日常使用（每次插上手机）

```bash
# 1. 插 USB（手机弹「允许 USB 调试」→ 勾选"一律允许"）
# 2. 拉回 WSL：
~/bin/attach-phone.sh
# 3. 看到 device 状态后开发：
cd ~/e-ink/app/focus_card && flutter run    # 热重载：改代码按 r
```

> ⚠️ 手机插回期间，**Windows 侧不要跑 `adb.exe devices`** 等命令——Windows adb server 会抢占设备，抢走后重跑 attach 脚本即可恢复。
> 💡 尽量固定用同一个 USB 口，BUSID 保持 `2-2`，永远不需要重新 bind。

## 4. attach-phone.sh（`~/bin/attach-phone.sh`）

自动完成四步：

1. 停 Windows adb server（`adb.exe kill-server`）
2. `usbipd list` 自动识别手机 BUSID（匹配 `22d9:2765 / ADB Interface`）
3. `usbipd attach --wsl --busid <识别结果>`（已 Attached 则跳过）
4. `adb devices -l` 验证并打印结果判读

异常处理：

| 脚本输出 | 处理 |
| --- | --- |
| ❌ 没找到手机 | 检查数据线（非充电线）/ USB 调试开关 |
| ⚠️ 设备未共享（Not shared） | 换了 USB 口 → 按脚本提示在**管理员 PowerShell** 执行 `usbipd bind --busid <新BUSID>`，再重跑脚本 |

## 5. 故障排查表

| 症状 | 原因 | 解法 |
| --- | --- | --- |
| `adb devices` 空 | attach 掉了（拔线/重启） | `~/bin/attach-phone.sh` |
| `unauthorized` | 手机未授权本机 adb key | 手机上点「允许 USB 调试」（勾"一律允许"） |
| `no permissions` | udev 规则未生效 | `sudo chmod 666 /dev/bus/usb/001/*`（应急）；规则文件在则重载：`sudo udevadm control --reload-rules && sudo udevadm trigger` |
| attach 报错 / 设备被占 | Windows adb server 在跑 | `adb.exe kill-server` 后重新 attach（脚本已内置） |
| usbipd list 里 Not shared | 换了 USB 口 | 管理员 PowerShell：`usbipd bind --busid <新BUSID>`（一次性） |
| flutter 找不到设备 | PATH 未生效 | 新开终端（`.bashrc` 已配好）或 `source ~/.bashrc` |
| flutter 报缺 SDK 36 | Flutter 升级后要求更高 SDK | `sdkmanager "platforms;android-36" "build-tools;36.0.0"`（按需升版本号） |

## 6. 完整重建步骤（换机器 / 重装时照此恢复）

### WSL2 侧

```bash
# 1. 系统包
sudo apt update && sudo apt install -y openjdk-17-jdk-headless unzip zip jq usbutils curl git

# 2. Android SDK（用户目录，免 sudo）
mkdir -p ~/android-sdk/cmdline-tools
curl -Lo /tmp/cmdtools.zip https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip
unzip -q /tmp/cmdtools.zip -d ~/android-sdk/cmdline-tools/
mv ~/android-sdk/cmdline-tools/cmdline-tools ~/android-sdk/cmdline-tools/latest
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
yes | ~/android-sdk/cmdline-tools/latest/bin/sdkmanager --licenses
~/android-sdk/cmdline-tools/latest/bin/sdkmanager \
  "platform-tools" "build-tools;36.0.0" "platforms;android-36" "platforms;android-35" "platforms;android-34"

# 3. Flutter（自动取最新 stable）
STABLE_URL=$(curl -s https://storage.googleapis.com/flutter_infra_release/releases/releases_linux.json | \
  python3 -c "import json,sys; d=json.load(sys.stdin); h=d['current_release']['stable']; \
  r=next(x for x in d['releases'] if x['hash']==h); print(d['base_url']+'/'+r['archive'])")
curl -Lo /tmp/flutter.tar.xz "$STABLE_URL" && tar -xf /tmp/flutter.tar.xz -C ~

# 4. 环境变量（~/.bashrc 追加）
cat >> ~/.bashrc <<'EOF'
# === flutter_dev_env ===
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
export ANDROID_HOME="$HOME/android-sdk"
export ANDROID_SDK_ROOT="$HOME/android-sdk"
export PATH="$PATH:$HOME/flutter/bin:$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin"
EOF
source ~/.bashrc

# 5. udev 规则（adb USB 权限）
sudo tee /etc/udev/rules.d/51-android.rules > /dev/null <<'EOF'
SUBSYSTEM=="usb", ATTR{idVendor}=="22d9", MODE="0666"
SUBSYSTEM=="usb", ATTR{idVendor}=="2a70", MODE="0666"
SUBSYSTEM=="usb", ATTR{idVendor}=="18d1", MODE="0666"
SUBSYSTEM=="usb", ATTR{idVendor}=="2717", MODE="0666"
SUBSYSTEM=="usb", ATTR{idVendor}=="12d1", MODE="0666"
SUBSYSTEM=="usb", ATTR{idVendor}=="04e8", MODE="0666"
SUBSYSTEM=="usb", ATTR{idVendor}=="2d95", MODE="0666"
EOF
sudo udevadm control --reload-rules && sudo udevadm trigger

# 6. 验证
flutter doctor    # Flutter + Android toolchain 两项须 ✓
```

### Windows 侧（管理员 PowerShell）

