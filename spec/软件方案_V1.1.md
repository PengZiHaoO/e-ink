> **定位：** 一块让"勿扰"变成实体、把"专注"变成记录的卡。
> 核心原则：**卡片是快照，App 是活账本。**

## 1. 定位

产品的 Job：

> **"我在专注，让世界和我自己都知道。"**

- **卡片** = 当前状态的快照（bistable，零功耗，不显示实时秒数）
- **App** = 专注记录的活账本（实时、可累计、可统计）

硬件让专注**可见**，软件让专注**可累计**。

---

## 2. 核心交互：翻转即更新

```text
打开App → 点击开始专注
        ↓
翻转手机（背面朝上）
        ↓
NFC写入 → 卡片显示 "FOCUSING 14:32"
        ↓
（专注结束）翻转回来 → NFC写入 → 卡片更新为下一状态
```

- **翻转 = 语义**：倒扣手机本就是全人类默认的"我在忙"手势，我们让这个手势留下痕迹。
- **一次会话只有 2 次翻转 / 2 次 NFC 写入**，能量负担极小。
- 卡片上只写**开始时间 / 状态 / 符号**，不写实时秒数（无电池不能持续刷新）。

---

## 3. 专注状态机

```text
专注中 → 休息 → 专注中 → ... → 可打扰 / 离开
```

每种状态对应一张卡片模板：

| 状态 | 卡片内容 | 语义 |
| --- | --- | --- |
| 专注中（Focusing） | FOCUSING · 开始时间 · 勿扰中 | 别打扰我 |
| 休息中（Break） | BREAK · 可打扰 | 我在休息，可以找 |
| 可打扰（Available） | AVAILABLE | 空闲 |
| 离开（Away） | AWAY · 回来时间 | 人不在 |
| 名片/身份（可选） | 姓名 · 职位 · 二维码 | 社交场景 |

---

## 4. 专注记录（Focus Records）= 留存引擎

- 每次专注 = 一条记录（开始 / 结束 / 时长 / 状态切换）
- 每日 / 每周统计、连续天数 streak
- 与 iOS Focus / 屏幕时间联动（开始专注时同步系统勿扰）
- **翻转次数 = 专注的物理账本**，反向提供给 App

> 这是极稚们做不了的：它们做"图片 + AI 生图"，我们做**行为数据 + 状态机**。
> 软件的粘性在这里，硬件的重复使用也在这里。

---

## 5. Smart Refresh

专注卡内容 = 文字 + 符号，载荷**几百 B ~ 几 KB**，Diff 几乎天然成立：

```text
旧画面 + 新状态 → Diff Engine → 只更新变化区域
```

收益：传输短 / 刷新快 / 取能少 —— **直接反哺硬件能量预算**。

---

## 6. Widget SDK（长期壁垒，V2）

官方基础 Widget：Clock / Calendar / QR / Music / Weather / Todo / Countdown / Status

```text
Widget SDK
Input: Time / Calendar / Music / Health / API
Output: 1-bit bitmap
```

目标生态：**E-Ink Widget Store**。V1 不依赖它，V2 建立壁垒。

---

## 7. AI：自动设计你的背屏

**不做 AI 聊天机器人。** AI 的职责是自动生成卡片。

> "帮我做一个低调的商务专注状态。"

AI 自动完成：排版 / 黑白化 / 选字体 / 信息密度控制 / 二维码。

> "帮我做一个像 90 年代掌机一样的黑白专注主题。"

直接生成电子纸 UI。

---

## 8. Physical Notification → 物理勿扰信号

卡片本身就是一块**看得见的勿扰牌**——不需要后台权限，不需要实时推送。

- 第一代**不宣传"实时通知"**
- 承诺：**下一次翻转时自动同步最新状态**

---

## 9. One Tap / One Flip

```text
Save → Flip → Done
```

不要：打开App → 配对 → 连接 → 选择设备 → 上传 → 等待……

> 产品最大的优势就是：没有电池、没有配对、没有充电。软件保持同样的极简。

---

## 10. App 首页：专注记录（不是设备管理）

```text
        今日专注 2h 14m

       ┌──────────────┐
       │   FOCUSING   │
       │    14:32     │
       └──────────────┘

    [ 开始专注 ]  [ 翻转到卡片 ]

   今日：3 次 ｜ 最长 47m ｜ 连续 5 天
```

用户打开 App 第一眼看到的是**自己的专注账本**，而不是设备列表。
